# ナワバリバトル

スプラトゥーン風の陣地取りゲームです。コンピュータと対戦して、より多くの陣地を塗りましょう！

## 遊び方

1. **セットアップ**
```bash
npm install
npm run build
```

2. **ゲーム起動**
`index.html` をブラウザで開きます。

3. **操作方法**（スマホのタッチ操作が前提）
- **移動**: 右の操作エリアをドラッグ（触れた位置がスティックの中心になり、倒した量で速さが変わる）
- **必殺技**: ⭐を2つ取ってゲージが溜まったら左の SP ボタンをタップ
- **ゲーム開始 / もう一度**: 盤面上のボタンをタップ
- **音**: 盤面右上のボタンで BGM・効果音のオン/オフを切り替え（設定はブラウザに保存）
- PC ではキーボード（WASD / 矢印キーで移動、スペースで開始・必殺技）でも遊べます

## ルール

- プレイヤー（青）とコンピュータ（赤）が移動して陣地を塗り合います
- 移動した場所が自動的に自分の色に塗られます
- 制限時間は30秒
- 時間終了時により多くの陣地を塗った方が勝ちです
- 勝つたびに CPU のレベルが上がります（最大 Lv.20）。レベルが上がるほど CPU は速くなり、塗れていない場所やあなたの陣地を狙い、Lv.3 からは⭐を集めて必殺技も使います
- レベルはブラウザに保存され、スタート画面の「Lv.1 からやり直す」で戻せます
