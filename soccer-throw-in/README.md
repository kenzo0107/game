# ⚽ サッカー スローイン ゲーム 3D

サッカーのスローインでボールをどこまで飛ばせるかチャレンジする3Dゲームです。

## 🎮 遊び方

スマホでもPCでも、画面全体を使って操作します。

1. 画面を**長押し**すると、選手がボールを頭上に構えてパワーゲージが往復します
2. 押したまま**上下にスライド**して投げる角度（15〜75°）を決めます
3. ゲージを見て**指を離す**と投げます
4. 結果画面を**タップ**すると、すぐに次の1投を構えます

PCではマウスで同じ操作ができるほか、スペースキー長押し＋↑↓キーでも遊べます。
縦画面では投げる選手の背後から、横画面では真横からボールを追います。

## 🚀 起動方法

```bash
# ブラウザでindex.htmlを開く
open index.html
```

または、シンプルなHTTPサーバーを起動:

```bash
# Python 3を使用
python -m http.server 8000

# ブラウザで http://localhost:8000 を開く
```

## 🎯 ゲーム機能

- ✅ **フル3Dグラフィックス**: Three.jsによるリアルな3D表現
- ✅ **パワーゲージシステム**: 0-100%のタイミングゲーム
- ✅ **物理演算**: リアルな放物線運動とボール回転
- ✅ **飛距離計算**: メートル単位で正確に計測
- ✅ **ベストスコア記録**: localStorage使用
- ✅ **影とライティング**: 臨場感のある影とライト効果
- ✅ **カメラワーク**: ボールを追従するダイナミックなカメラ
- ✅ **レスポンシブデザイン**: 画面サイズに自動対応

## 🛠️ 技術スタック

- **Three.js r128**: 3Dグラフィックスエンジン
- **HTML5**: 構造とレイアウト
- **CSS3**: スタイリングとUI
- **Vanilla JavaScript**: ゲームロジック

## 💡 カスタマイズ

`game.js`の以下の定数を変更することで、ゲームバランスを調整できます:

```javascript
const GRAVITY = 0.02;        // 重力（大きいほど早く落下）
const MAX_POWER = 1.2;       // 最大パワー（大きいほど遠くまで飛ぶ）
const POWER_SPEED = 120;     // パワーゲージの速さ（%/秒）
const ANGLE_PER_PIXEL = 0.2; // スライド1pxあたりの角度変化
```

カメラ位置は `setCameraTarget` 関数で縦画面・横画面ごとに調整できます。
