# Pilot Wings Game

パイロットウイングス風の3Dフライトシミュレーションゲーム

## 技術スタック

- Three.js: 3Dグラフィックス
- TypeScript: 型安全な開発
- Vite: 高速な開発サーバー

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開く

## 操作方法

- **W/S**: スロットル（加速/減速）。着陸後の S はブレーキ
- **↑/↓**: ピッチ（機首下げ/機首上げ）
- **←/→**: ロール（かたむけると、その方向へ旋回する）
- **Q/E**: ヨー（機首左右）。着陸後はハンドル
- **Enter**: 決定 / **R**: やり直し

## ステージ

| # | 名前 | ポイント |
|---|------|----------|
| 1 | はじめての着陸 | まっすぐ先の広い滑走路 |
| 2 | まがって着陸 | ななめ前の滑走路へ右旋回 |
| 3 | みじかい滑走路 | せまく短い滑走路でブレーキ |
| 4 | よこかぜ | 右からの風とななめの滑走路 |
| 5 | ちいさな島 | 小さな島・左からの風・少ない燃料 |
| 6 | スカイダイビング | 飛行機から飛び降り、パラシュートで的に降りる |

くぐったリングは緑に変わってそのまま残る。

### スカイダイビング（ステージ 6）

高度 600 から飛び降り、自由落下中に水平に置かれた 4 つのリングを上から下へくぐる。パラシュートを開いたら島の的へ向かって降りる。

| ボタン | 自由落下中 | パラシュート |
|--------|------------|--------------|
| スティック | 前後左右へ移動 | 左右で旋回、上で加速、下でブレーキ |
| 急降下 | 頭を下げて速く落ちる | - |
| ゆっくり | 手足を広げてゆっくり落ちる | ブレーキ |
| 向き←→ | 向きを変える | 旋回 |
| パラシュート | パラシュートを開く | - |

- 高度 150 を切ってもパラシュートを開いていないと「パラシュートを開こう！」と警告する
- 開かずに地面へ着く、開くのが遅く速いまま着地する、海に降りると失敗
- 星は「着地」「リングを全部くぐる」「的のまん中（赤）に降りる」で最大3つ

滑走路への進入コース（滑走路の手前 300 の扇形の範囲）の外で高度 12 を下回ると、「高度が低すぎる！」の表示と警告音で知らせる。

着陸して止まればクリアで、短いファンファーレが鳴り、画面のどこかをタップすると次のステージへ進む。星は「着陸」「リングを全部くぐる」「滑走路の上で止まる」で最大3つ。進み具合は localStorage に保存する。

## 音

タイヤが滑走路に着いた瞬間に擦れる音、滑走中は速さと路面（滑走路/草地）に応じた走行音が鳴る。

BGM は Web Audio で鳴らす落ち着いた曲で、メニューの「♪ BGM」ボタンで切り替えられる（選んだ曲は localStorage に保存）。

| 曲 | 雰囲気 |
|----|--------|
| Blue Horizon | エレピとブラシ系ドラムのフュージョン（86 BPM） |
| Morning Glide | ドラムをほぼ使わないゆったりしたアンビエント（70 BPM） |
| Sky Waltz | ビブラフォン風のメロディのジャズワルツ（3 拍子） |
| Sunset Approach | ナイロンギター風の伴奏の少し切ないボサノヴァ |

メニューではドラムとメロディを抜いた静かな版、飛行中はフル編成になり、墜落するとフェードアウトする。

トップページで音を OFF にしていると鳴らない。
